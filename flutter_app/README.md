# كنوز KENOZ — Flutter

هذا مشروع Flutter مستقل يجري تطويره بجانب نسخة Android/WebView القديمة للحفاظ على النسخة الأصلية أثناء التحويل.

## التخزين دون إنترنت
- ملف الكتاب المقدس يُضمّن كأصل محلي داخل التطبيق.
- أي استجابة API ناجحة تُحفظ تلقائيًا في ملفات JSON داخل مجلد التطبيق.
- عند فشل الاتصال، تُعرض آخر نسخة محفوظة لنفس الرابط.
- الملاحظات تحفظ محليًا على الجهاز.

## البناء
من هذا المجلد:
`flutter pub get`
`flutter build apk --debug`

ملاحظة: نسخة الكتاب المقدس تُنزّلها مهمة GitHub Actions من مصدرها وتتحقق من وجود 66 سفرًا. يجب مراجعة ترخيص النص قبل توزيع التطبيق.
